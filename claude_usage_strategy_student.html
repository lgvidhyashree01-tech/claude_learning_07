Biggest mistakes to avoid

Using Max effort for everything. It's slower and consumes more of your usage limits. Standard handles 80% of your daily tasks just fine.
Vague prompts. "Help me with Python" gets a generic answer. "I'm getting a KeyError on line 12, here's my code: [code]" gets a real fix. Context is everything.
Not iterating. Claude's first answer is a draft, not a final answer. Push back, ask for improvements, and request a better version.
Skipping Opus for hard problems. If you've asked Sonnet the same question twice and it still doesn't click — switch to Opus. Don't waste time on the wrong tier.
Copying without understanding. For coding and research, always ask Claude to explain what it did. You need to understand the output, not just use it.
Starting a new chat for every question. Claude has no memory between chats. Keep your project conversations in one thread so it has full context throughout.
